# Sovrium Scoop Bucket

[Scoop](https://scoop.sh) bucket for installing [Sovrium](https://sovrium.com) on Windows.

## Installation

```powershell
# Add this bucket
scoop bucket add sovrium https://github.com/sovrium/scoop-bucket

# Install Sovrium
scoop install sovrium
```

## Update

```powershell
scoop update sovrium
```

## About Sovrium

Sovrium is a configuration-driven web application platform. Define your app in YAML, JSON, or TypeScript and deploy instantly.
